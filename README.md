# ヨミキリ（yomikiri）

**AIがあなたの癖をその場で学習する、カイジ風・限定ジャンケン賭博。** 完全ブラウザ内動作（送信なし・ライブラリゼロ）。`index.html` を開くだけ。

## ルール

- 互いに✊✌️🖐×4枚=12枚の消費制。**残り札は互いに公開**（終盤は札読みの詰将棋）
- チップ10枚、毎ラウンドベット1〜3。勝者が総取り。あいこはポット持ち越し（札だけ減る）
- **ヨミキリ宣言**: AIは確信が高いと、あなたが出す前に宣言してくる。宣言時、的中されて負けると+2毟られ、裏をかいて勝つと+2奪える
- 毎ラウンド後、AIが**なぜその手を読んだか**をあなたの実測統計で開示（後出し編集なし＝G4で検証）
- **⛓ 後出し防止（コミット・リベール）**: 選択前に🔒ハッシュ（手＋読み＋確信度＋nonce のSHA-256）、ラウンド後に🔓元文字列を黙って表示するだけ。検証は疑う人が自分でやる設計（「一致✓」等の自己申告は出さない＝本人方針）。純JS SHA-256はnodeのcryptoと505ケース一致検証済み

## ボス

| ボス | 頭脳 | 記憶 |
|---|---|---|
| 🐣 見習いデク | 頻度カウント＋札カウントのみ。宣言は詰みの時だけ | 試合内 |
| 👁 中堅サトリ | NN(hidden8)・毎ラウンド本物のSGDでオンライン学習 | 試合内 |
| 😈 悪魔ラプラス | NN(hidden16)・オンライン学習 | **全対戦をlocalStorage永続**（あなた専用に育つ） |

## 検証済みバランス（`node sim_balance.js`・全PASS）

- 堅実プレイ（残り札比例）に対し全ボスのラウンド勝率50%±1（**ズルなし**）
- デクは思考が公開情報のみ→逆読みボットで平均+5チップ（**読めば勝てる**）
- 癖のあるボット（勝ち後同手・循環・お気に入り手）はAI勝率60〜67%で搾取される
- 後追いカウンター型は試合内で45%→55%に読み返される。ラプラスは持ち越し学習で試合1の44.8%→試合4-5で60.4%（**対戦するほど強くなる**）
- 開示された読み筋の数値は内部統計と完全一致（正直な開示）

## 技術

- 予測: 24次元特徴（直近3手・直前結果・両者残り札・負け後手変え傾向・連続長・AIの直前手）→小型NN→softmax。学習はdamashi-aiでPyTorchパリティ検証済みのSGDエンジン（cnn.js headTrainStep）を流用
- AIの出し手: 予測分布への期待値最適応手＋確信度に応じたスタック平衡混合
- 原作IPは不使用（メカニクスのオマージュ＋オリジナルキャラ・世界観）
